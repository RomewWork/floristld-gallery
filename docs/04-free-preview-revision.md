# 免费方案决议

用户已选择随时在手机或电脑登录网站上传；固定电脑管理方案已排除。

采用 Cloudflare Pages/Workers/D1/Access + ImageKit Free。公开免费预览、管理员邮箱验证码登录；允许你和管理员两个邮箱。浏览器生成高清展示图，原画独立备份。

私有主文件和公开副本均占容量，1000张不是免费容量保证。当前 ImageKit 免费3 GB存储、20 GB/月流量，超限可停止服务；用户接受此边界。不开通付费计划、不自动升级，自定义域名续费与图片费用分开。

本地演示使用 IndexedDB，明确显示提示，不发送验证码或上传云端。生产所有管理请求经 Access 校验。部署与恢复见 deployment.md、backup-restore.md。
