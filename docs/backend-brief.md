Implement Cloudflare Worker API + D1 migrations for bilingual gallery with one-to-many collections/artworks, assets, profile, upload sessions. Use D1 native bindings and jose for Cloudflare Access JWT validation (issuer https://ACCESS_TEAM_DOMAIN, audience ACCESS_AUD, ADMIN_EMAILS comma-separated). All /api/admin requests validate signature, issuer, exp and email, plus Origin on mutation. Fail closed if missing config. For localhost API development allow explicit DEV_AUTH only with env ENVIRONMENT=development AND loopback hostname; never production. Public read CORS only configured PUBLIC_ORIGIN, admin same-origin when worker ASSETS serves exported admin. Worker can serve ASSETS fallback with Access verification on all non-public routes, public API stays public. Admin /admin/ static page handled via ASSETS.

GET /api/public/gallery -> GalleryData published collections/artworks verified only, no private asset IDs/fileIds (can blank fileId), no management info except shared defaults needed. Query slug filters collection, limit default24 max100 and cursor offset; response may add nextCursor. For homepage include published covers and first artworks limited. GET /api/admin/gallery -> GalleryData all records plus signed private preview urls. GET /api/admin/me -> {email}.
POST /api/admin/collections body {slug,title,description} -> Collection. PATCH /api/admin/collections/:id with editable fields + version -> Collection. POST /api/admin/artworks body {collectionId,assetId,title,description,alt,year} -> Artwork. PATCH /api/admin/artworks/:id -> Artwork.
POST /api/admin/{collections|artworks}/:id/{publish|unpublish|restore} body {version} -> updated record. DELETE /api/admin/{collections|artworks}/:id body {version} soft delete. DELETE /api/admin/{collections|artworks}/:id/permanent body {version} only already-deleted, provider cleanup careful referenced files. POST /api/admin/collections/:id/order {artworkIds,version} enforce exact membership and optimistic concurrency. PATCH /api/admin/profile -> Profile. GET /api/admin/export -> JSON metadata.
Upload: POST /api/admin/uploads {fileName,bytes,mime} <=5,000,000 -> UploadTicket (ImageKit v1 auth HMAC, fixed random folder/name, 5min). Frontend upload ImageKit isPrivateFile=true; POST /api/admin/uploads/:sessionId/complete {fileId} -> Asset. Verified provider details not client URLs. Sessions single-use, atomic claims, robust errors. Request body size small.
