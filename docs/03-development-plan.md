# 开发执行计划

## 顺序
1. 初始化 Next/TypeScript/Tailwind、共用类型、双语文案、演示适配层。
2. 首页、合集、About、灯箱和艺术展册样式。
3. D1、Access校验、合集/作品管理API。
4. 在线后台、浏览器图片预处理、直传、验证、发布。
5. 回收站、导出、错误恢复、可访问性和动效。
6. 类型/lint/关键逻辑/API/端到端测试、生产导出与Worker构建。
7. 真实账户联调、预发布、真图上传、验证码收件与区域网络实测。

## 验收
公众免登录；草稿不泄露；允许的两个邮箱可管理；未授权写操作拒绝；合集一对多；排序持久化；中英切换保持上下文；上传失败可恢复；原文件不修改；额度不自动产生账单。

## 状态
进度见 implementation-ledger.md，验证证据见 acceptance.md。模拟测试不能替代真实服务。缺凭证时先完成本地可验证实现，并明确列出部署缺项。
